# TechNova 2026 — Registration Form Demo

A responsive front-end project created to test KaushalProof's Registration Form challenge.

## Files
- `index.html` — accessible registration form and event details
- `style.css` — responsive layout and visual styles
- `script.js` — client-side validation and demo success state

## Run locally
Open `index.html` in a modern browser. No build tools or dependencies are required.

## Deploy
Upload the three website files (`index.html`, `style.css`, `script.js`) to a static host such as Netlify, or publish the repository with a static-site hosting service.

## Important limitations
- This is a front-end demonstration. It does not send registrations to a server.
- A successful message demonstrates client-side validation only, not a real booking.
- The latest successful demo submission may be saved in this browser's local storage.
- Do not enter sensitive or real attendee information.
- For a KaushalProof evaluation, publish the site publicly and provide the matching public GitHub repository and live URL.
